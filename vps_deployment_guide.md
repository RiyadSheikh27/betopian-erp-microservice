# Betopian Server — Hosting Guide

> **Project:** `betopian-server`
> **Domain:** `social-media.betopiagroup.com`
> **VPS path:** `/root/betopian-server/`
> **Stack:** Django + Daphne (ASGI) + PostgreSQL + Redis + Coturn + Nginx + Docker

---

## Project File Map

```
/root/betopian-server/
├── Dockerfile
├── docker-compose.yml
├── requirements.txt
├── .env
├── config/
│   └── asgi.py
├── coturn/
│   └── turnserver.conf
├── staticfiles/          ← auto-generated by collectstatic (Docker volume)
└── media/                ← user uploads (Docker volume)

/etc/nginx/sites-enabled/
├── betopian-server       ← main Django app proxy config
└── ai-course-outline.betopiagroup.com  ← separate static frontend

/etc/letsencrypt/         ← SSL certs managed by Certbot
```

---

## Services Overview

| Service | What it does | Port |
|---|---|---|
| `web` (Daphne) | Django ASGI server | `8000` (internal) |
| `db` (PostgreSQL 16) | Main database | `5432` (internal) |
| `redis` (Redis 7) | Channel layer for Django Channels | `6379` (internal) |
| `coturn` | TURN/STUN server for WebRTC | `3478`, `5349`, `49152–65535` |
| Nginx | Reverse proxy + SSL termination | `80`, `443` (public) |

## Restart Cheatsheet

### After changing Django code

```bash
cd /root/betopian-server
docker compose build web
docker compose up -d web
```

Or just restart without rebuilding (if no dependency changes):

```bash
docker compose restart web
```

### After changing `requirements.txt`

Always rebuild the image:

```bash
cd /root/betopian-server
docker compose build web
docker compose up -d web
```

### After changing `.env`

```bash
cd /root/betopian-server
docker compose up -d web
```

Docker reads `.env` on container start, so no rebuild needed — just recreate the container.

### After changing `docker-compose.yml`

```bash
cd /root/betopian-server
docker compose up -d
```

### After changing `coturn/turnserver.conf`

```bash
cd /root/betopian-server
docker compose restart coturn
```

### After changing Nginx config

```bash
# Test config first — always do this before reloading
nginx -t

# If test passes, reload (no downtime)
systemctl reload nginx

# Full restart if needed
systemctl restart nginx
```

### After changing SSL certificates (Certbot)

Certbot auto-renews, but to manually reload after cert update:

```bash
systemctl reload nginx
```

## Deploy a Fresh Code Update (Full Flow)

```bash
cd /root/betopian-server

# 1. Pull latest code
git pull

# 2. Rebuild and restart web container
docker compose build web
or,
docker compose build --no-cache web
docker compose up -d web

# All in one
docker compose down && docker compose build --no-cache web && docker compose up -d

# 3. Check logs to confirm everything started
docker compose logs -f web
```

## Database

### Run migrations manually

```bash
cd /root/betopian-server
docker compose exec web python manage.py migrate
```

### Access PostgreSQL shell

```bash
docker compose exec db psql -U postgres -d betopian
```

### Backup the database

```bash
docker compose exec db pg_dump -U postgres betopian > backup_$(date +%Y%m%d).sql
```

### Restore from backup

```bash
cat backup_20240101.sql | docker compose exec -T db psql -U postgres -d betopian
```

## Static & Media Files

Static files are collected into `/root/betopian-server/staticfiles/` and served directly by Nginx.
Media files (uploads) live in `/root/betopian-server/media/`.

Nginx serves them at:
- `https://social-media.betopiagroup.com/static/` → `/root/betopian-server/staticfiles/`
- `https://social-media.betopiagroup.com/media/` → `/root/betopian-server/media/`

To manually re-collect static files:

```bash
docker compose exec web python manage.py collectstatic --noinput
```

## TURN Server (Coturn)

Config file: `/root/betopian-server/coturn/turnserver.conf`

- Runs in `network_mode: host` — uses VPS ports directly (not Docker NAT)
- External IP: `social-media.betopiagroup.com`
- Auth secret must match `TURN_SECRET` in `.env`
- Ports used: `3478` (STUN/TURN), `5349` (TLS), `49152–65535` (relay range)

After any config change:

```bash
docker compose restart coturn
```

## Full Stack Restart (Nuclear Option)

Bring everything down and back up:

```bash
cd /root/betopian-server
docker compose down
docker compose up -d
```

> ⚠️ This causes brief downtime. DB data is safe — it lives in the `postgres_data` Docker volume.

## Second Site (ai-course-outline)

This is a **separate static frontend**, not related to the Django app.

- Nginx config: `/etc/nginx/sites-enabled/ai-course-outline.betopiagroup.com`
- Files served from: `/var/www/ai-course-outline/`
- Domain: `ai-course-outline.betopiagroup.com`

To update it, just replace the files in `/var/www/ai-course-outline/` and reload Nginx:

```bash
systemctl reload nginx
```
